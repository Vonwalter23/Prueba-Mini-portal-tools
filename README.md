# Prueba técnica de Mini Portal Tools

Repositorio público independiente destinado exclusivamente a una prueba técnica temporal de compatibilidad con GitHub Pages.

## Alcance y límites

- No es el entorno de producción ni el hosting definitivo.
- No incluir datos sensibles, secretos, credenciales ni documentación interna del proyecto privado.
- No habilitar la publicación de GitHub Pages hasta completar la copia mínima, adaptar las rutas y revisar las pruebas.
- No configurar dominio propio, DNS, analytics ni monetización en esta prueba.

## Estado

Inicialización documental. La aplicación aún no se ha copiado ni publicado.
